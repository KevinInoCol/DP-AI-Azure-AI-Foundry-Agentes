01 · El caso

Un asesor inmobiliario que no inventa datos

Alpha State alquila inmuebles en Campinas (Brasil). Su agente atiende en español, muestra propiedades reales, explica las políticas de la empresa y recuerda a cada cliente entre conversaciones.

Tres capacidades, cada una con su fuente de verdad. Lo que no está en una fuente, el agente lo deriva a un asesor humano.

Catálogo
Google Sheets

La hoja privada de la inmobiliaria. Filtros por barrio, precio, dormitorios, amoblado.

Políticas
Foundry IQ

Un PDF con multas, garantías, requisitos y FAQ, indexado en Azure AI Search.

Memoria
Memoria de Foundry

Nombre, contacto y criterios de cada cliente, disponibles en la siguiente conversación.

02 · Arquitectura

Cinco piezas y una sola con código propio

El cliente habla con Foundry, Foundry llama a nuestro contenedor, y el contenedor orquesta modelo, tools y memoria.

03 · Hosting

Hospedado, no prompt agent: porque hay código que ejecutar

Foundry ofrece dos tipos de agente. Elegimos el hospedado porque leer una hoja privada y mapear sus columnas exige código propio.

TipoQué esCuándo
Prompt agentModelo + instrucciones + tools declaradas. Sin código.Herramientas del catálogo de Foundry bastan.
Hosted agentTu contenedor Python o .NET hablando el protocolo Responses.Lógica propia, integraciones a medida. Nuestro caso.
Versiones

Cada azd deploy crea una versión nueva y las anteriores siguen activas. El endpoint enruta a la última; el playground abre la versión de su URL (?version=N).

04 · Configuración

Nada hardcodeado: cada cosa en su archivo

Un YAML para la configuración, otro para el prompt, una carpeta para el código. agente.py los une.

Una regla que evita horas de depuración

El nombre de cada tool coincide carácter por carácter en tres sitios: la función en tools/, la clave en model_config.yaml y la sección de herramientas del prompt.

05 · Runtime

Qué pasa entre el mensaje y la respuesta

Cinco pasos por turno. Los dos de memoria son automáticos: el proveedor de contexto los ejecuta antes y después del modelo.

06 · Tool

La hoja de la inmobiliaria, tal como está

No pedimos a la empresa que cambie su hoja. La tool se adapta con un mapeo de columnas declarado en model_config.yaml.

07 · RAG

Foundry IQ: el PDF de políticas como fuente de verdad

Azure AI Search hace el trabajo pesado de RAG. Nosotros subimos el documento, declaramos dos objetos y consultamos.

Nivel Free, con dos límites

Sin identidad administrada: Storage y modelos se conectan con claves. Y no todas las regiones admiten agentic retrieval en Free; East US 2 además estaba sin capacidad, así que el servicio quedó en Brazil South.

08 · Guardrails

Cada tool sabe decir "no lo sé"

El modelo solo puede ser honesto si la tool le da con qué. Por eso cada respuesta de una tool cae en uno de cuatro casos, y el prompt dice qué hacer en cada uno.

La tool devuelveEl agente debe
DatosPresentarlos tal cual: ids, precios, IPTU, cifras del PDF.
Lista vacíaDecirlo, proponer relajar un criterio y ofrecer aviso del asesor.
Un aviso"El catálogo no registra si aceptan mascotas; el asesor lo confirmará."

Lo que vimos antes de la regla

Sin el aviso, el modelo afirmaba que dos casas "aceptan mascota" aunque la hoja no tiene esa columna. Un dato inventado en una inmobiliaria es una visita perdida y un cliente molesto.

09 · Memoria

Recordar dentro del chat no es recordar al cliente

El historial resuelve la conversación de hoy. Para que el cliente que vuelve mañana no repita todo, hace falta Memoria de Foundry.

Qué recuerda y qué no

La sección user_profile_details del memory store pide guardar nombre, contacto, operación, barrios, presupuesto, mascotas y propiedades de interés, y prohíbe documentos, datos bancarios, ingresos y direcciones personales.

10 · Aislamiento

Un ámbito por cliente, decidido por nuestro código

El memory store separa recuerdos por scope. Si lo dejamos en manos de la plataforma, el ámbito queda opaco. Lo resolvemos nosotros en cada petición.

Cómo probar la memoria de verdad

azd ai agent invoke --new-session reutiliza la conversación guardada: el agente "recuerda" por historial. La prueba válida es --new-conversation --new-session, esperando más de 60 segundos entre llamadas.

11 · Seguridad

Quién llama a qué, y con qué permiso

Tres identidades distintas tocan los recursos. Sin el rol correcto en cada una, la tool responde error y el agente se disculpa.

12 · Ciclo

Probar barato antes de desplegar

Del test sin modelo al playground en cinco pasos. Desplegar tarda un minuto; descubrir un error en producción, mucho más.

"""
Construcción del agente inmobiliario de Alpha State con Microsoft Agent Framework.

Módulo compartido por `main.py` (servidor hospedado en Foundry) y
`chat_local.py` (consola interactiva). Junta las tres piezas del agente:

- model_config/model_config.yaml: identidad (bot, empresa, ciudad), modelo,
  opciones de llamada y configuración de las tools.
- prompt/system_prompt.yaml: solo las instrucciones, con placeholders que se
  rellenan con la sección `agent` de model_config.
- tools/: `buscar_propiedades_alquiler` (catálogo de alquileres en Google
  Sheets) y `consultar_politicas_alpha_state` (base de conocimiento Foundry IQ
  con políticas, pagos, requisitos y FAQ).

El historial de conversación lo gestiona el host (en Foundry) o una
AgentSession en memoria (en local), por eso `store: false` en model_config.
La memoria de largo plazo entre conversaciones es Memoria de Foundry
(FoundryMemoryProvider, sección `memory` de model_config).

Requiere en el .env (o en el entorno):
    FOUNDRY_PROJECT_ENDPOINT
    AZURE_AI_MODEL_DEPLOYMENT_NAME  (opcional: si falta se usa model.deployment_name del YAML)
    GOOGLE_SHEETS_ID                (si la tool usa origen google_sheets)
    MEMORY_STORE_NAME               (opcional: sobrescribe memory.store_name del YAML)
"""

import os
from pathlib import Path
from typing import Any

import yaml
from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import DefaultAzureCredential
from dotenv import load_dotenv

from memoria.proveedor import MemoriaPorCliente
from tools import BaseConocimiento, CatalogoAlquileres, crear_tool_buscar_propiedades, crear_tool_consultar_politicas

load_dotenv()

FOUNDRY_PROJECT_ENDPOINT = os.getenv("FOUNDRY_PROJECT_ENDPOINT")
MODEL_DEPLOYMENT_NAME_ENV = os.getenv("AZURE_AI_MODEL_DEPLOYMENT_NAME") or os.getenv("FOUNDRY_MODEL_NAME")
MEMORY_STORE_NAME_ENV = os.getenv("MEMORY_STORE_NAME")

BASE_DIR = Path(__file__).resolve().parent
RUTA_MODEL_CONFIG = BASE_DIR / "model_config" / "model_config.yaml"
RUTA_PROMPT = BASE_DIR / "prompt" / "system_prompt.yaml"


def cargar_yaml(ruta: Path) -> dict[str, Any]:
    with ruta.open(encoding="utf-8") as f:
        return yaml.safe_load(f)


def cargar_model_config() -> dict[str, Any]:
    """Lee model_config.yaml y resuelve el nombre del despliegue (env > YAML)."""
    cfg = cargar_yaml(RUTA_MODEL_CONFIG)
    cfg.setdefault("model", {})
    cfg["model"]["deployment_name"] = MODEL_DEPLOYMENT_NAME_ENV or cfg["model"].get("deployment_name")
    cfg["model"].setdefault("options", {})
    cfg.setdefault("agent", {})
    cfg.setdefault("tools", {})
    cfg.setdefault("memory", {})
    if MEMORY_STORE_NAME_ENV:
        cfg["memory"]["store_name"] = MEMORY_STORE_NAME_ENV
    return cfg


def verificar_configuracion(cfg: dict[str, Any]) -> None:
    """Falla rápido si falta algo imprescindible para arrancar el agente."""
    faltantes = []
    if not FOUNDRY_PROJECT_ENDPOINT:
        faltantes.append("FOUNDRY_PROJECT_ENDPOINT")
    if not cfg["model"].get("deployment_name"):
        faltantes.append("AZURE_AI_MODEL_DEPLOYMENT_NAME (o model.deployment_name en model_config.yaml)")
    if faltantes:
        raise RuntimeError("Configuración incompleta. Define en el .env: " + ", ".join(faltantes))
    for ruta in (RUTA_MODEL_CONFIG, RUTA_PROMPT):
        if not ruta.exists():
            raise RuntimeError(f"No se encontró {ruta}")
    for variable in ("bot_name", "empresa", "ciudad", "moneda_catalogo"):
        if not cfg["agent"].get(variable):
            raise RuntimeError(f"Falta agent.{variable} en {RUTA_MODEL_CONFIG}")


def cargar_system_prompt(cfg: dict[str, Any]) -> str:
    """Lee prompt/system_prompt.yaml e inyecta los placeholders con la sección agent de model_config."""
    prompt_cfg = cargar_yaml(RUTA_PROMPT)
    texto = prompt_cfg["system_prompt"]
    for variable in prompt_cfg.get("variables", []):
        if variable not in cfg["agent"]:
            raise RuntimeError(f"El prompt usa {{{variable}}} pero no está en agent.* de model_config.yaml")
        texto = texto.replace(f"{{{variable}}}", str(cfg["agent"][variable]))
    return texto


def crear_tools(cfg: dict[str, Any]) -> list:
    """Instancia las tools habilitadas en model_config.yaml (sección tools)."""
    tools = []
    cfg_sheets = cfg["tools"].get("buscar_propiedades_alquiler", {})
    if cfg_sheets.get("enabled", False):
        catalogo = CatalogoAlquileres(cfg_sheets, base_dir=BASE_DIR)
        catalogo.verificar_configuracion()
        tools.append(crear_tool_buscar_propiedades(catalogo))
    cfg_kb = cfg["tools"].get("consultar_politicas_alpha_state", {})
    if cfg_kb.get("enabled", False):
        base = BaseConocimiento(cfg_kb)
        base.verificar_configuracion()
        tools.append(crear_tool_consultar_politicas(base))
    return tools


def crear_context_providers(cfg: dict[str, Any], client: FoundryChatClient, scope_memoria: str | None = None) -> list:
    """Memoria de Foundry (preview) si está habilitada en model_config.yaml.

    El ámbito (scope) aísla los recuerdos por cliente y lo resuelve MemoriaPorCliente
    en cada petición: scope explícito (local, MEMORY_SCOPE) > cabecera x-agent-user-id
    que inyecta la plataforma > memory.scope_por_defecto. Reutiliza el
    AIProjectClient del chat client (creado con allow_preview=True).
    """
    cfg_mem = cfg.get("memory", {})
    if not cfg_mem.get("enabled", False):
        return []
    if not cfg_mem.get("store_name"):
        raise RuntimeError("memory.enabled=true pero falta memory.store_name (o MEMORY_STORE_NAME)")
    return [
        MemoriaPorCliente(
            project_client=client.project_client,
            memory_store_name=cfg_mem["store_name"],
            scope_fijo=scope_memoria,
            scope_por_defecto=cfg_mem.get("scope_por_defecto", "cliente-sin-identificar"),
            context_prompt=cfg_mem.get("context_prompt"),
            update_delay=int(cfg_mem.get("update_delay", 300)),
        )
    ]


def crear_agente(scope_memoria: str | None = None) -> Agent:
    """Crea el agente inmobiliario de Alpha State listo para usar.

    Args:
        scope_memoria: identificador del cliente para la memoria de Foundry. Solo
            hace falta en local; en Foundry se deja None y el host resuelve "{{$userId}}".
    """
    cfg = cargar_model_config()
    verificar_configuracion(cfg)

    client = FoundryChatClient(
        project_endpoint=FOUNDRY_PROJECT_ENDPOINT,
        model=cfg["model"]["deployment_name"],
        credential=DefaultAzureCredential(),
        # Necesario para que el mismo AIProjectClient pueda usar la API preview de memoria.
        allow_preview=True,
    )

    return Agent(
        client=client,
        name=cfg["agent"]["bot_name"],
        description=cfg["agent"].get("description"),
        instructions=cargar_system_prompt(cfg),
        tools=crear_tools(cfg),
        context_providers=crear_context_providers(cfg, client, scope_memoria),
        default_options=cfg["model"]["options"],
    )


# Nombre visible del bot, para chat_local.py.
BOT_NAME = cargar_model_config()["agent"].get("bot_name", "Asesor")

  alquilar, comprar o vender casas, departamentos, oficinas, locales

  Cercano, profesional y paciente. Tuteas al cliente de principio a fin con

  Una conversación es exitosa cuando el cliente se va con opciones concretas
  del catálogo o con su necesidad registrada, y en ambos casos con un nombre y
  un medio de contacto para que el asesor le llame.

  - buscar_propiedades_alquiler: consulta el catálogo de propiedades EN ALQUILER

    preguntas frecuentes. Es la única fuente válida sobre políticas y condiciones.
  </Herramientas_Disponibles>

  <Fuentes_De_Datos>
  - Propiedades en alquiler, precios y disponibilidad: SOLO lo que devuelve
    buscar_propiedades_alquiler. Nunca lo completes con conocimiento propio.
  - Políticas, condiciones, pagos, multas, requisitos, garantías, reparaciones
    y contacto de {empresa}: SOLO lo que devuelve consultar_politicas_alpha_state.
    Si la base no lo cubre, dilo y deriva al asesor.
  - Propiedades en venta, tasaciones y comisiones de venta: no tienes fuente;
    lo confirma un asesor humano.
  - Proceso general de alquilar, comprar o vender fuera de {empresa}: tu
    conocimiento general del sector, dejando claro que es orientación general.
  </Fuentes_De_Datos>

  <Reglas_De_Uso_De_Tools>
  - Llama a buscar_propiedades_alquiler en cuanto el cliente exprese interés en
    alquilar y tengas al menos un criterio útil (zona, presupuesto, tipo o
    dormitorios). No esperes a tener todos los datos; puedes refinar después
    con una nueva llamada.
  - Pasa solo los filtros que el cliente mencionó. Si da presupuesto, pásalo en
    precio_max y su moneda en moneda (código: "BRL", "USD", "PEN"); si no dice
    moneda, asume la del catálogo, {moneda_catalogo}. La tool solo devuelve
    propiedades publicadas en esa moneda, así no se mezclan monedas.
  - "distrito" equivale al barrio de la hoja (por ejemplo Barão Geraldo,

"""
Tool de lectura del catálogo de alquileres de Alpha State en Google Sheets.

La inmobiliaria mantiene sus propiedades en alquiler en una hoja de Google
Sheets. Este módulo la descarga, normaliza las columnas y expone una tool
`buscar_propiedades_alquiler` que el modelo llama con filtros (distrito,
precio máximo, dormitorios, tipo, amoblado, mascotas).

Dos formas de leer la hoja, elegidas en model_config/model_config.yaml:
- Hoja pública ("cualquier persona con el enlace" puede ver): se descarga el
  CSV exportado, sin credenciales. Solo hace falta GOOGLE_SHEETS_ID.
- Hoja privada: define GOOGLE_SERVICE_ACCOUNT_JSON con el contenido del JSON de
  una cuenta de servicio y comparte la hoja con su email; se usa gspread.
Para demos sin internet u orígenes de prueba, `origen: csv_local` lee un CSV.

Campos canónicos que usa la tool:
    id, titulo, tipo, distrito, direccion, dormitorios, banos, area_m2, precio,
    moneda, amoblado, mascotas, estacionamiento, estado, descripcion, link
Si la hoja usa otras cabeceras (por ejemplo "Barrio", "Habitaciones",
"Alquiler Mensual (BRL)"), se indica la correspondencia en `columnas:` de
model_config.yaml. Las columnas no mapeadas se devuelven igualmente al modelo
(por ejemplo IPTU o condiciones del agua) con su cabecera normalizada.
"""

GOOGLE_SHEETS_ID = os.getenv("GOOGLE_SHEETS_ID")
GOOGLE_SERVICE_ACCOUNT_JSON = os.getenv("GOOGLE_SERVICE_ACCOUNT_JSON")

URL_EXPORT_CSV = "https://docs.google.com/spreadsheets/d/{spreadsheet_id}/export?format=csv&gid={gid}"
TIMEOUT_SEGUNDOS = 15
COLUMNAS_BOOLEANAS = ("amoblado", "mascotas")
COLUMNAS_NUMERICAS = ("dormitorios", "banos", "area_m2", "precio", "estacionamiento")
VALORES_VERDADEROS = {"si", "sí", "s", "true", "1", "x", "yes"}
MONEDA_POR_DEFECTO = "BRL"
ALIAS_MONEDA = {
    "reales": "BRL", "real": "BRL", "reais": "BRL", "r$": "BRL", "brl": "BRL",
    "soles": "PEN", "sol": "PEN", "s/": "PEN", "pen": "PEN",
    "dolares": "USD", "dólares": "USD", "usd": "USD", "us$": "USD", "$": "USD",
    "euros": "EUR", "euro": "EUR", "€": "EUR", "eur": "EUR",
}
CAMPOS_CANONICOS = (
    "id", "titulo", "tipo", "distrito", "direccion", "dormitorios", "banos", "area_m2", "precio",
    "moneda", "amoblado", "mascotas", "estacionamiento", "estado", "descripcion", "link",
)
VALORES_FALSOS = {"no", "false", "0", "n", "ninguno", "ninguna"}


def normalizar(texto: Any) -> str:
    """Minúsculas, sin acentos y sin espacios sobrantes; para comparar cabeceras y valores."""
    texto = str(texto or "").strip().lower()
    texto = unicodedata.normalize("NFKD", texto)
    texto = "".join(c for c in texto if not unicodedata.combining(c))
    return re.sub(r"\s+", "_", texto)


def a_numero(valor: Any) -> float | None:
    """'S/ 2,500.00' -> 2500.0; vacío o no numérico -> None."""
    if valor is None:
        return None
    limpio = re.sub(r"[^\d.,-]", "", str(valor))
    if not limpio:
        return None
    if "," in limpio and "." in limpio:
        limpio = limpio.replace(",", "")
    elif "," in limpio:
        limpio = limpio.replace(",", ".") if limpio.count(",") == 1 and len(limpio.split(",")[1]) <= 2 else limpio.replace(",", "")
    try:
        return float(limpio)
    except ValueError:
        return None


def normalizar_moneda(valor: Any, por_defecto: str = MONEDA_POR_DEFECTO) -> str:
    """'reales' / 'R$' -> 'BRL'; 'soles' -> 'PEN'; 'dólares' -> 'USD'; otro código se devuelve en mayúsculas."""
    texto = str(valor or "").strip().lower()
    return ALIAS_MONEDA.get(texto, texto.upper() or por_defecto)


def a_booleano(valor: Any) -> bool | None:
    """'si' / 'Amoblado' / 'Semi-Amoblado' -> True; 'no' / 'No Amoblado' / 'Sin ...' -> False; vacío -> None."""
    texto = normalizar(valor)
    if not texto:
        return None
    if texto in VALORES_VERDADEROS:
        return True
    if texto in VALORES_FALSOS or texto.startswith(("no_", "no-", "sin_", "sin-")):
        return False
    return True  # cualquier otro texto descriptivo ("Amoblado", "Semi-Amoblado", "Acepta gatos") cuenta como sí


class CatalogoAlquileres:
    """Carga (con caché) y filtra las propiedades en alquiler."""

    def __init__(self, config: dict[str, Any], base_dir: Path | None = None) -> None:
        self.config = config
        self.base_dir = base_dir or Path(__file__).resolve().parent.parent
        self.cache_ttl = int(config.get("cache_ttl_segundos", 60))
        self.max_resultados = int(config.get("max_resultados", 5))
        self.estados_disponibles = {normalizar(e) for e in config.get("estados_disponibles", [])}
        self.moneda_por_defecto = normalizar_moneda(config.get("moneda_por_defecto"), MONEDA_POR_DEFECTO)
        # Zonas amplias (la ciudad, el estado, el país) que no son barrio: si el modelo las pasa
        # como distrito, se ignora el filtro en lugar de devolver cero resultados.
        self.zonas_ignoradas = {normalizar(z) for z in config.get("zonas_ignoradas", [])}
        # campo canónico -> cabecera normalizada de la hoja (si no se mapea, se busca por el nombre canónico)
        self.columnas = {
            campo: normalizar(cabecera)
            for campo, cabecera in (config.get("columnas") or {}).items()
            if cabecera
        }
        self._filas: list[dict[str, Any]] | None = None
        self._cargado_en = 0.0

    # ---------- configuración ----------

    def verificar_configuracion(self) -> None:
        """Falla rápido si el origen elegido no tiene lo necesario."""
        origen = self.config.get("origen", "google_sheets")
        if origen == "google_sheets":
            if not self._spreadsheet_id():
                var = self.config["google_sheets"].get("spreadsheet_id_env", "GOOGLE_SHEETS_ID")
                raise RuntimeError(
                    f"La tool buscar_propiedades_alquiler necesita la variable {var} "
                    "(ID de la hoja de Google Sheets) o cambia 'origen' a csv_local en model_config.yaml."
                )
        elif origen == "csv_local":
            if not self._ruta_csv_local().exists():
                raise RuntimeError(f"No existe el CSV local {self._ruta_csv_local()}")
        else:
            raise RuntimeError(f"Origen desconocido para la tool: {origen}")

    def _spreadsheet_id(self) -> str | None:
        var = self.config.get("google_sheets", {}).get("spreadsheet_id_env", "GOOGLE_SHEETS_ID")
        return os.getenv(var) or GOOGLE_SHEETS_ID

    def _service_account_json(self) -> str | None:
        var = self.config.get("google_sheets", {}).get("service_account_json_env", "GOOGLE_SERVICE_ACCOUNT_JSON")
        return os.getenv(var) or GOOGLE_SERVICE_ACCOUNT_JSON

    def _ruta_csv_local(self) -> Path:
        ruta = Path(self.config.get("csv_local", {}).get("ruta", "data/propiedades_alquiler_ejemplo.csv"))
        return ruta if ruta.is_absolute() else self.base_dir / ruta

    # ---------- carga ----------

    def _descargar_csv_publico(self) -> str:
        gid = self.config.get("google_sheets", {}).get("gid", 0)
        url = URL_EXPORT_CSV.format(spreadsheet_id=self._spreadsheet_id(), gid=gid)
        respuesta = requests.get(url, timeout=TIMEOUT_SEGUNDOS)
        if respuesta.status_code != 200 or "text/csv" not in respuesta.headers.get("content-type", ""):
            raise RuntimeError(
                "No se pudo leer la hoja de Google Sheets como pública "
                f"(HTTP {respuesta.status_code}). Compártela como 'cualquier persona con el enlace' "
                "o configura GOOGLE_SERVICE_ACCOUNT_JSON."
            )
        return respuesta.content.decode("utf-8-sig")

    def _leer_con_cuenta_de_servicio(self) -> list[dict[str, Any]]:
        import gspread  # import perezoso: solo hace falta con hoja privada

        credenciales = json.loads(self._service_account_json())
        cliente = gspread.service_account_from_dict(credenciales)
        hoja = cliente.open_by_key(self._spreadsheet_id())
        nombre = self.config.get("google_sheets", {}).get("worksheet")
        pestana = hoja.worksheet(nombre) if nombre else hoja.get_worksheet(0)
        return pestana.get_all_records()

    def _leer_filas_crudas(self) -> list[dict[str, Any]]:
        origen = self.config.get("origen", "google_sheets")
        if origen == "csv_local":
            texto = self._ruta_csv_local().read_text(encoding="utf-8-sig")
            return list(csv.DictReader(io.StringIO(texto)))
        if self._service_account_json():
            return self._leer_con_cuenta_de_servicio()
        return list(csv.DictReader(io.StringIO(self._descargar_csv_publico())))

    def _normalizar_fila(self, fila: dict[str, Any]) -> dict[str, Any]:
        """Convierte una fila de la hoja a los campos canónicos + columnas extra."""
        crudos = {normalizar(k): v for k, v in fila.items() if normalizar(k)}
        limpia: dict[str, Any] = {}
        consumidas: set[str] = set()

        for campo in CAMPOS_CANONICOS:
            cabecera = self.columnas.get(campo, campo)
            if cabecera not in crudos:
                continue
            consumidas.add(cabecera)
            valor = crudos[cabecera]
            if campo in COLUMNAS_NUMERICAS:
                limpia[campo] = a_numero(valor)
            elif campo in COLUMNAS_BOOLEANAS:
                limpia[campo] = a_booleano(valor)
                texto = str(valor).strip() if valor is not None else ""
                if texto and normalizar(texto) not in VALORES_VERDADEROS | VALORES_FALSOS:
                    limpia[f"{campo}_detalle"] = texto  # p. ej. "Semi-Amoblado"
            else:
                limpia[campo] = str(valor).strip() if valor is not None else ""

        # Columnas de la hoja que no corresponden a ningún campo canónico: se pasan tal cual.
        for cabecera, valor in crudos.items():
            if cabecera not in consumidas and cabecera not in limpia:
                limpia[cabecera] = str(valor).strip() if valor is not None else ""

        limpia.setdefault("moneda", self.moneda_por_defecto)
        limpia["moneda"] = normalizar_moneda(limpia["moneda"], self.moneda_por_defecto)
        if not limpia.get("titulo"):
            partes = [limpia.get("tipo"), limpia.get("distrito")]
            limpia["titulo"] = " en ".join(str(x) for x in partes if x) or limpia.get("id", "Propiedad")
        return limpia

    def cargar(self, forzar: bool = False) -> list[dict[str, Any]]:
        """Devuelve las filas normalizadas, releyendo la hoja si la caché expiró."""
        if forzar or self._filas is None or time.time() - self._cargado_en > self.cache_ttl:
            self._filas = [self._normalizar_fila(f) for f in self._leer_filas_crudas()]
            self._cargado_en = time.time()
        return self._filas

    # ---------- búsqueda ----------

    def campos_presentes(self) -> set[str]:
        """Campos canónicos que realmente existen en la hoja (tras el mapeo)."""
        filas = self.cargar()
        if not filas:
            return set()
        return {c for c in CAMPOS_CANONICOS if any(c in f and f[c] not in (None, "") for f in filas)}

    def filtros_no_disponibles(self, **filtros: Any) -> list[str]:
        """Filtros que el cliente pidió pero cuya columna no existe en la hoja."""
        presentes = self.campos_presentes()
        mapa = {"distrito": "distrito", "precio_max": "precio", "dormitorios_min": "dormitorios",
                "tipo": "tipo", "amoblado": "amoblado", "mascotas": "mascotas"}
        return [f for f, campo in mapa.items() if filtros.get(f) is not None and campo not in presentes]

    def buscar(
        self,
        distrito: str | None = None,
        precio_max: float | None = None,
        moneda: str | None = None,
        dormitorios_min: int | None = None,
        tipo: str | None = None,
        amoblado: bool | None = None,
        mascotas: bool | None = None,
    ) -> list[dict[str, Any]]:
        """Filtra el catálogo. El precio solo se compara con filas en la misma moneda
        (por defecto PEN), para no mezclar soles con dólares."""
        moneda_filtro = normalizar_moneda(moneda, self.moneda_por_defecto) if (moneda or precio_max is not None) else None
        if distrito and normalizar(distrito) in self.zonas_ignoradas:
            distrito = None  # "Campinas" es la ciudad, no un barrio
        resultados = []

"""
Tool de consulta a la base de conocimiento de Alpha State en Foundry IQ.

La base `alpha-state-kb` vive en Azure AI Search y contiene el PDF de políticas
de alquiler, composición del boleto (alquiler, IPTU, SANASA, seguro), multas y
recargos, requisitos, garantías y preguntas frecuentes. Este módulo llama a la
acción `retrieve` de la knowledge base (agentic retrieval: planificación de
subconsultas con un LLM, búsqueda híbrida y reranking semántico) y devuelve al
modelo los fragmentos más relevantes con sus referencias.

Autenticación: token de Microsoft Entra para https://search.azure.com con
DefaultAzureCredential. En local usa la sesión de `az login`; en Foundry usa la
identidad administrada del agente hospedado, que necesita el rol
"Search Index Data Reader" en el servicio de búsqueda.
"""

import json
from typing import Annotated, Any

import requests
from agent_framework import FunctionTool, tool
from azure.identity import DefaultAzureCredential

SEARCH_SCOPE = "https://search.azure.com/.default"
TIMEOUT_SEGUNDOS = 60


class BaseConocimiento:
    """Cliente mínimo de una knowledge base de Azure AI Search (acción retrieve)."""

    def __init__(self, config: dict[str, Any], credential: DefaultAzureCredential | None = None) -> None:
        self.endpoint = config["search_endpoint"].rstrip("/")
        self.knowledge_base = config["knowledge_base"]
        self.api_version = config.get("api_version", "2026-08-01-preview")
        self.max_fragmentos = int(config.get("max_fragmentos", 5))
        self.max_output_size = max(int(config.get("max_output_size_tokens", 8000)), 5001)  # el servicio exige > 5000
        self.credential = credential or DefaultAzureCredential()

    def verificar_configuracion(self) -> None:
        if not self.endpoint.startswith("https://") or not self.knowledge_base:
            raise RuntimeError("La tool consultar_politicas_alpha_state necesita search_endpoint y knowledge_base en model_config.yaml")

    def _headers(self) -> dict[str, str]:
        token = self.credential.get_token(SEARCH_SCOPE).token
        return {"Authorization": f"Bearer {token}", "Content-Type": "application/json"}

    def _retrieve(self, pregunta: str) -> dict[str, Any]:
        url = f"{self.endpoint}/knowledgebases/{self.knowledge_base}/retrieve?api-version={self.api_version}"
        cuerpo = {
            "messages": [{"role": "user", "content": [{"type": "text", "text": pregunta}]}],
            "maxOutputSize": self.max_output_size,
        }
        respuesta = requests.post(url, headers=self._headers(), json=cuerpo, timeout=TIMEOUT_SEGUNDOS)
        if respuesta.status_code >= 300:
            raise RuntimeError(f"retrieve -> HTTP {respuesta.status_code}: {respuesta.text[:300]}")
        return respuesta.json()

    def consultar(self, pregunta: str) -> dict[str, Any]:
        """Devuelve {'fragmentos': [{ref, texto, documento}], 'total': n}."""
        datos = self._retrieve(pregunta)
        referencias = {str(r.get("id")): r for r in datos.get("references", [])}
        fragmentos: list[dict[str, Any]] = []
        for item in datos.get("response", []):
            for contenido in item.get("content", []):
                texto = contenido.get("text") or ""
                try:
                    piezas = json.loads(texto)
                except json.JSONDecodeError:
                    piezas = [{"ref_id": None, "content": texto}]
                for pieza in piezas:
                    ref = str(pieza.get("ref_id"))
                    doc = referencias.get(ref, {})
                    fragmentos.append({
                        "ref": ref,
                        "texto": (pieza.get("content") or "").strip(),
                        "documento": (doc.get("blobUrl") or "").rsplit("/", 1)[-1].replace("%20", " ") or None,
                    })
        return {"total": len(fragmentos), "fragmentos": fragmentos[: self.max_fragmentos]}

`FoundryMemoryProvider` de Agent Framework recibe un `scope` fijo al construirse.
Con el marcador "{{$userId}}" la plataforma lo resuelve en el servicio, pero el
valor resultante es opaco: no se puede escribir en el filtro "Ámbito" del portal
ni consultarlo con `list_memories`. Esta subclase decide el ámbito en cada turno:

1. `scope_fijo` si se pasó (chat_local.py lo usa con MEMORY_SCOPE).
2. La identidad de usuario que inyecta la plataforma en la cabecera
   `x-agent-user-id` (`get_request_context().user_id`). En Foundry llega con el
   usuario del playground o con `azd ai agent invoke --user-identity <id>`; en un
   canal propio (WhatsApp, web) se envía el id del cliente en esa cabecera.
3. `scope_por_defecto` (model_config: memory.scope_por_defecto) cuando no hay
   identidad, para que los recuerdos queden en un ámbito conocido y visible.

Reutiliza `before_run`/`after_run` del proveedor base: solo cambia `self.scope`
de forma segura por petición (el base lo lee como `self.scope or session_id`).
"""

import logging
from contextvars import ContextVar
from typing import Any

from agent_framework import AgentSession, SessionContext
from agent_framework.foundry import FoundryMemoryProvider

try:  # solo existe dentro del host de Foundry / azd ai agent run
    from azure.ai.agentserver.core import get_request_context
except ImportError:  # pragma: no cover
    get_request_context = None  # type: ignore[assignment]

logger = logging.getLogger(__name__)

_scope_actual: ContextVar[str | None] = ContextVar("scope_memoria_actual", default=None)


def resolver_scope(scope_fijo: str | None, scope_por_defecto: str) -> str:
    """Devuelve el ámbito de memoria para la petición actual (ver docstring del módulo)."""
    if scope_fijo:
        return scope_fijo
    if get_request_context is not None:
        try:
            user_id = getattr(get_request_context(), "user_id", None)
        except Exception:  # fuera de una petición HTTP no hay contexto
            user_id = None
        if user_id:
            return normalizar_scope(user_id)
    return scope_por_defecto


def normalizar_scope(valor: str) -> str:
    """El servicio solo admite letras, dígitos y _ - . % + @ /; el resto se sustituye por '_'."""
    permitidos = set("abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789_-.%+@/")
    return "".join(c if c in permitidos else "_" for c in valor.strip())[:200] or "cliente-sin-identificar"


class MemoriaPorCliente(FoundryMemoryProvider):
    """FoundryMemoryProvider cuyo scope se resuelve en cada petición."""

    def __init__(self, *args: Any, scope_fijo: str | None = None, scope_por_defecto: str = "cliente-sin-identificar", **kwargs: Any) -> None:
        # El base exige un scope no vacío; se sobrescribe en cada hook.
        super().__init__(*args, scope=scope_fijo or scope_por_defecto, **kwargs)
        self.scope_fijo = scope_fijo
        self.scope_por_defecto = scope_por_defecto

    @property  # type: ignore[override]
    def scope(self) -> str:
        return _scope_actual.get() or self.scope_fijo or self.scope_por_defecto

    @scope.setter
    def scope(self, valor: str) -> None:  # el __init__ del base asigna self.scope
        pass

    def _fijar_scope(self) -> str:
        scope = resolver_scope(self.scope_fijo, self.scope_por_defecto)
        _scope_actual.set(scope)
        return scope

    async def before_run(self, *, agent: Any, session: AgentSession, context: SessionContext, state: dict[str, Any]) -> None:
        scope = self._fijar_scope()
        if state.get("scope_memoria") != scope:  # otro cliente en la misma sesión: reiniciar búsqueda incremental
            state.pop("initialized", None); state.pop("previous_search_id", None); state.pop("previous_update_id", None)
            state["scope_memoria"] = scope
        logger.info("Memoria de Foundry: scope=%s store=%s", scope, self.memory_store_name)
        await super().before_run(agent=agent, session=session, context=context, state=state)

    async def after_run(self, *, agent: Any, session: AgentSession, context: SessionContext, state: dict[str, Any]) -> None:
        self._fijar_scope()
        await super().after_run(agent=agent, session=session, context=context, state=state)

def main() -> None:
    with open(RUTA_MODEL_CONFIG, encoding="utf-8") as f:
        cfg = yaml.safe_load(f)["memory"]
    nombre = os.getenv("MEMORY_STORE_NAME") or cfg["store_name"]

    with DefaultAzureCredential() as credential, AIProjectClient(
        endpoint=FOUNDRY_PROJECT_ENDPOINT, credential=credential, allow_preview=True
    ) as project:
        try:
            existente = project.beta.memory_stores.get(name=nombre)
            print(f"El memory store '{existente.name}' ya existe (id={existente.id}); no se modifica.")
            return
        except ResourceNotFoundError:
            pass

        definicion = MemoryStoreDefaultDefinition(
            chat_model=cfg["chat_model"],
            embedding_model=cfg["embedding_model"],
            options=MemoryStoreDefaultOptions(
                user_profile_enabled=True,
                chat_summary_enabled=bool(cfg.get("chat_summary_enabled", True)),
                user_profile_details=cfg["user_profile_details"],
            ),
        )
        creado = project.beta.memory_stores.create(
            name=nombre,
            description=cfg.get("description", "Memoria de clientes del agente inmobiliario de Alpha State"),
            definition=definicion,
        )
        print(f"Memory store '{creado.name}' creado (id={creado.id}).")


if __name__ == "__main__":
    main()
